# Concept B · Library

**Gallery-first: a better Photos app that also plays everything.**

A Windows 11 navigation pane (folders, favourites, recent) and a justified, date-grouped grid
of photos and videos together. Opening an item keeps the folder in view as a filmstrip and puts
details, audio/subtitle tracks and speed in a side pane. Trim is a mode of the same viewer: the
pane turns into the segment list, and a timeline card appears under the video.

**Best for:** replacing the Photos app day to day. It is the most familiar to Windows users and
gives the clearest path from "browse" to "watch" to "cut".

**Trade-offs**
- More chrome around the media than Cinema; full screen hides it.
- The timeline is roomier than Cinema's but less dense than Studio's.
- Closest to the current app's structure (side panel, bottom bar, edit mode), and video sits in
  a rectangle beside the panes, which suits the native video window. This is the cheapest to build.
